# Research — 2026-10-29

## 1. เว็บ 3 ตัว ใช้ได้แค่ไหน

| เว็บ | ใช้เป็นแรงบันดาลใจ | เอาไฟล์มาใช้ในคลิปจริง | สรุป |
|---|---|---|---|
| **myinstants.com** (ปุ่มเสียงมีม) | ✅ ดูว่าเสียงมีมไทยอะไรกำลังฮิต แล้วสังเคราะห์เสียงแนวเดียวกันขึ้นเอง | ❌ ไฟล์อัปโหลดโดยผู้ใช้ ไม่มีใบอนุญาต หลายเสียงตัดมาจากหนังหรือทีวี | อ้างอิงอย่างเดียว ห้ามดาวน์โหลดมาใส่คลิป |
| **giphy.com** | ✅ ดูจังหวะท่าทางและมุก reaction ไว้อ้างอิงตอนวาด | ❌ เงื่อนไขการใช้งานห้ามใช้เชิงพาณิชย์ ถ้าคลิปหารายได้ถือว่าเป็นเชิงพาณิชย์ | ใช้เป็นภาพอ้างอิงท่าทางเท่านั้น |
| **Envato (Elements / app)** | ✅ | ✅ **ถ้าสมัครสมาชิก** ใบอนุญาตผูกกับโปรเจกต์ ต้องลงทะเบียนต่อคลิป มีเสียงประกอบหลายแสนเสียง | ตัวเลือกเดียวในสามตัวที่ใช้เสียงในคลิปที่หารายได้ได้ถูกต้อง (เสียเงิน) |

**แนวทางของโปรเจกต์:** เสียงประกอบยังสังเคราะห์ด้วยโค้ดเหมือนเดิม ฟรีและไม่มีปัญหาลิขสิทธิ์ ถ้าวันหนึ่งสมัคร Envato ค่อยเพิ่มโฟลเดอร์ `assets/sfx/` สำหรับไฟล์ที่ลงทะเบียนใบอนุญาตแล้ว

## 2. ElevenLabs แพ็กฟรี

- ใช้ API ได้ ได้ **10,000 ตัวอักษรต่อเดือน** เมื่อใช้รุ่น v3 หรือ Multilingual (รุ่น Flash หรือ Turbo ได้ 20,000 แต่ไม่รองรับภาษาไทย)
- **เสียงที่ใช้ผ่าน API ได้คือเสียงสำเร็จรูปประมาณ 21 เสียง** (ตัวเลขจากผู้ทดลองใช้ ไม่ใช่เอกสารทางการ) เสียงใน Voice Library กว่าหมื่นเสียง **ใช้ผ่าน API ไม่ได้ถ้าเป็นบัญชีฟรี** (ตามเอกสารทางการ)
- สร้างเสียงของตัวเองได้ 3 ช่อง แต่โคลนเสียงระดับโปรไม่ได้
- **ใช้เชิงพาณิชย์ไม่ได้** ต้องเป็นแพ็ก Starter ขึ้นไป
- ตอนพากย์ตอนที่ 1 ใช้ไปประมาณ 360 ตัวอักษรต่อตอน ทั้งเดือนทำได้ประมาณ 25 ตอน
- **ทำให้ได้หลายเสียงในแพ็กฟรี:** ให้ตัวละครแต่ละตัวใช้เสียงสำเร็จรูปคนละเสียง และใส่โทนเสียงของรุ่น v3 เช่น `[whispers]`, `[scared]`, `[nervous]`

## 3. TTS ภาษาไทยฟรีหรือ open source

| ตัวเลือก | ข้อดี | ใบอนุญาต | ใช้กับคลิปที่หารายได้ได้ไหม |
|---|---|---|---|
| **KhanomTan TTS** (เรียกผ่าน PyThaiTTS) | รันในเครื่อง มีหลายเสียง | Apache-2.0 (ข้อมูลจากแหล่งรอง ต้องเช็กที่ repo จริง) | น่าจะได้ ✅ |
| **PyThaiTTS** (ตัวเรียกใช้) | ใช้ง่าย สลับโมเดลได้ (lunarlist, khanomtan, vachana) | โค้ด Apache-2.0 ส่วนโมเดลแต่ละตัวต้องเช็กแยก | แล้วแต่โมเดล |
| **F5-TTS-THAI** (VIZINTZOR) | โคลนเสียงจากตัวอย่างสั้นๆ ได้ เสียงเป็นธรรมชาติ | ป้ายบอกว่า CC-BY-4.0 แต่โมเดลฐาน F5-TTS เป็น CC-BY-NC | ⚠️ ยังไม่ชัด ถือว่าใช้ได้แค่แบบไม่หารายได้ |
| **ThonburianTTS** | ออกเสียงไทยแม่น โคลนเสียงได้ | โค้ด MIT แต่โมเดล CC BY-NC-SA | ❌ ใช้ได้แค่แบบไม่หารายได้ |
| **Meta MMS-TTS (tha)** | เล็ก รันเร็ว | CC-BY-NC 4.0 | ❌ |
| **Typhoon2-Audio** | ตัวเลข CER ดีที่สุดในงานวิจัย | Apache-2.0 แต่ repo ถูก archive แล้ว และเป็นโมเดลเสียงคุยโต้ตอบ ไม่ได้ทำมาเพื่อ TTS | ⚠️ ติดตั้งยาก |

**แนวทาง:** ให้ `tts` ในโปรเจกต์เลือกผู้ให้บริการเสียงได้ คือ `elevenlabs` เป็นค่าเริ่มต้น และ `khanomtan` สำหรับเสียงเพิ่มที่รันในเครื่อง ให้ตัวประกอบใช้เสียงในเครื่อง ส่วนตัวเล่าเรื่องใช้ ElevenLabs

## 4. skillsmp.com: ตัวที่มีประโยชน์กับเรา

ค้นไป 26 หมวด ได้แก่ storyboard, script, TTS, sound design, ffmpeg, animation, captions, TikTok, Thai และอื่นๆ จนชนโควตาวันละ 50 ครั้ง **ไม่มี skill ภาษาไทยหรือฟอนต์ไทยเลย**

| Skill | ประโยชน์ | สถานะ |
|---|---|---|
| `character-rigging`, `pose-library-design` (OpenMontage) | ทำตัวละครเป็นข้อมูล มีจุดหมุนให้แต่ละชิ้นส่วน มีคลังท่าทาง และลำดับ anticipation → action → hold → settle | **เอาแนวคิดมาเขียนเอง** ไม่ copy ไฟล์ เพราะ repo เป็น **AGPL-3.0** |
| `canvas-procedural-animation` (OpenMontage) | ที่ติดตั้งไว้แล้ว | ⚠️ repo เป็น AGPL-3.0 แม้ไฟล์จะเขียนว่า MIT ใช้ในเครื่องได้ แต่ห้ามใส่ใน repo เรา (กันไว้ใน `.gitignore` แล้ว) |
| `captions-overlay` (HeyGen HyperFrames) | แนวคิดซับแบบ rail / embed | ใช้ในเครื่อง ไม่ใส่ใน repo |
| `storyboard` (HBAI-Ltd), `storyboard-breaker` (chatfire-AI) | หลักทำให้ช็อตต่อเนื่องกัน (เขียนเป็นภาษาจีน) | เอาแนวคิดมาใส่ใน storyboard template |
| `content-engine` (affaan-m) | วิธีทำ content ให้เข้ากับแต่ละแพลตฟอร์ม เช่น hook ใน TikTok | อ่านเป็นแนวทางทำแคปชันและ hook |
| `sherpa-onnx-tts` (openclaw) | TTS แบบ offline | sherpa-onnx รองรับ MMS-tha (ใช้ได้แค่แบบไม่หารายได้) |
| `sound-design-direction` (a5c-ai), `sound-designer` (FerroxLabs) | ภาษาที่ใช้กำกับเสียงประกอบ | อ่านเป็นแนวทาง |

**สรุป:** ไม่มี skill ตัวไหนเอามาใช้ได้ทั้งตัวโดยไม่ต้องแก้ ของที่มีค่าที่สุดคือ "แนวคิด" ซึ่งจะถูกรวมไว้ใน skill ของเราเองชื่อ **TumraiKortum** และเขียนใหม่ทั้งหมด จะได้ไม่ติดใบอนุญาตของคนอื่น
