# Season 1: ปาร์ตี้ฮาโลวีน

**จบที่ 5 ตอนหลัก** โพสต์จริงประมาณ 6–7 คลิป ใช้แนวทาง "แตกทางแล้วกลับมารวมกัน" จำนวนคลิปจะได้ไม่เพิ่มขึ้นเป็นเท่าตัวทุกตอน

```
EP1 นับคน ──► ถอด? ──┬─ EP2A ถอด ─► เปิดประตู? ─┐
                     └─ EP2B ไม่ถอด ─► จับมือ? ──┤  (ทางที่แพ้โหวต = คลิปโบนัส ทำหรือไม่ทำก็ได้)
                                                 ▼
                          EP3 ตัวเลียนแบบเผยตัว ─► ใครคือตัวปลอม? (โหวต)
                                                 ▼
                          EP4 กติกาของมัน ─► คุณจะยอมถ่ายรูปหมู่อีกรูปไหม?
                                                 ▼
                          EP5 ตอนจบ: จบดี / จบร้าย (ตามผลโหวต)
```

| ตอน | คำถามที่ตอบ | คำถามใหม่ที่ทิ้งไว้ | ทางเลือกตอนจบ |
|---|---|---|---|
| EP1 | มีคนเกินมาจริงไหม | คุณเป็นใคร | ถอด / ไม่ถอด |
| EP2A ✅ | คุณเป็นคนจริง | ต้นตัวจริงคือคนไหน | เปิด / ไม่เปิด |
| EP2B | ตัวนั้นสวมรอยเป็นคุณ | คุณจะออกจากข้างนอกได้ยังไง | จับมือ / วิ่งหนี |
| EP3 | ตัวเลียนแบบมีอยู่จริง ไม่ว่ามาจากทางไหน | ตอนนี้มันเป็นใคร | ชี้ตัวปลอม (เลือก 1 จาก 3) |
| EP4 | มันสวมรอยได้ผ่านแฟลชถ่ายรูปตอนเที่ยงคืน | จะหยุดมันยังไง | ถ่ายรูป / ทำลายมือถือ |
| EP5 | กติกาทั้งหมด และสิ่งที่เกิดเมื่อปีที่แล้ว | (เปิดทางไว้ทำซีซัน 2) | จบดี / จบร้าย |

## กติกาการทำ

- เปิดทางเลือกค้างไว้พร้อมกันได้ไม่เกิน 2 ทาง
- ทางที่แพ้โหวตทำเป็นคลิปโบนัส "ถ้าคุณเลือกอีกทาง…" ทำเมื่อมีเวลา ตอนหลักไม่ต้องรอคลิปนี้
- ทุกตอนต้องตอบคำถามเก่า 1 ข้อ และเปิดคำถามใหม่ 1 ข้อ
- ลงประมาณทุก 2–3 วัน รอผลโหวตจากคอมเมนต์ 48 ชั่วโมง
- ทุกตอนใช้ห้องเดิม ตัวละครเดิม แล้วเพิ่มฉากใหม่ตอนละไม่เกิน 1–2 ฉาก งานจะได้ไม่บาน

## ระหว่างรอผลโหวต (ช่องเป็นช่องการ์ตูนแอนิเมชันทั่วไป)

- คลิปสั้น 10–20 วินาทีจากตัวละครเดิม เช่น "ผีไทยแต่ละตัวตอนอยู่บ้าน", มาสคอตครกตำของช่อง และเบื้องหลัง "วาดด้วยโค้ด"
- ซีซัน 2 ใช้ไอเดียจากที่ค้นไว้ เช่น น้ำท่วม หรือมิจฉาชีพโทรมาผิดคน (ดู `halloween-script.md`)
