## TikTok

**แคปชัน**
```
คุณเลือกไม่เปิดประตู… อย่าให้มันรู้ว่าคุณรู้ 👀
ตอนที่ 3 · ทางไม่เปิด (ทางที่โหวตชนะ)  ใครคือตัวปลอม? คอมเมนต์ชื่อมาเลย 👇
```

**แฮชแท็ก**
```
#ทำไรก็ทำ #ปาร์ตี้ฮาโลวีนมีคนเกิน #ตอนที่3 #ทุกอย่างถูกหมดยกเว้นเรื่องเดียว #เรื่องผี #ผีไทย #ฮาโลวีน #แอนิเมชัน
```

**คอมเมนต์ปักหมุด**
```
ยังไม่ได้ดูตอนที่ 1–2? ดูก่อนที่คลิปก่อนหน้า 👈
ใครคือตัวปลอม 👉 แม่นาก / กระสือ / นางตานี ?
คำตอบที่คนเลือกเยอะสุดได้ไปต่อตอนที่ 4 🔥
(เจอจุดที่ผิดแล้ว อย่าเพิ่งเฉลยนะ 🤫)
```

**ตั้งค่าก่อนโพสต์**
- ปก: ใช้ไฟล์ `out/cover-halloween-ep3.png`
- เปิดป้าย **AI-generated content** เพราะเสียงพากย์สร้างด้วย AI
- ใส่เครดิตเสียงท้ายคำอธิบาย: `Voice: ElevenLabs` เพราะเป็นเสียงจากแพ็กฟรี
- เพิ่มคลิปนี้เข้าเพลย์ลิสต์ "ปาร์ตี้ฮาโลวีน" ต่อจากตอนที่ 1–2
- ถ้าโพสต์หลังต้นพฤศจิกายน ให้ลบแท็ก `#ฮาโลวีน` ออก


## หลังปิดโหวต

```

```
