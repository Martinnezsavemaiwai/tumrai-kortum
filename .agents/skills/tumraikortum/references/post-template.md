# Post kit (write `<episode>/POST.md` after every render)

Same no-spoiler rule as the cover: the caption may say what the first 3 seconds say, never the turn or the clues.

```markdown
# EPn — <title> · post kit

## TikTok
**Caption** (≤ 150 chars before "more"; hook first, then the CTA)
<hook line in the voice of the opening rule> 👀
ตอนที่ n · <title>  เลือกทางในคอมเมนต์ 👇

**Hashtags** (5–8: 2 broad + 3–4 niche + series tag)
#ทำไรก็ทำ #<series tag> #ทุกอย่างถูกหมดยกเว้นเรื่องเดียว #เรื่องผี #ผีไทย #แอนิเมชัน #การ์ตูน

**Pinned comment**
เลือกเลย 👉 <A> หรือ <B> ?
ทางที่คนเลือกเยอะสุดได้ไปต่อตอนหน้า 🔥
(เจอจุดที่ผิดแล้วอย่าเพิ่งเฉลยนะ 🤫)

**Settings**
- Cover: out/cover-<episode>.png
- Turn on **AI-generated content** label (voices are AI)
- Voice credit in the description: "Voice: ElevenLabs" (free-plan audio)

## Reels / Shorts
Same caption + hashtags (Reels: up to ~5 tags read best). Shorts title ≤ 100 chars: "<title> (ตอนที่ n) #shorts"

## Next episode hook (for the pinned comment after the vote)
"ทาง <winner> ชนะ! ตอนที่ n+1 มาแล้ว 👉 @<channel>"
```

Rules:
- Thai first, emoji sparingly (≤ 3), no clickbait the video doesn't pay off.
- One series hashtag per story (e.g. `#ปาร์ตี้ฮาโลวีนมีคนเกิน`) so viewers can binge in order; add `#ตอนที่n`.
- Never reveal the "one wrong thing" in caption, tags or pinned comment — let viewers find it in the comments.
- Seasonal tags only while true (e.g. `#ฮาโลวีน` around Oct 31).
